# IPTV Player

Android IPTV player, Kotlin aur Jetpack Compose mein bana.

## Features
- M3U link ya file se playlist load
- Alag-alag playlists save karna
- Search, groups, favorites (M3U export)
- Channel logo, agla/pichhla channel
- Fullscreen, buffering aur auto retry
- Background recording aur MP4 export
- Dark theme

## Note
Is app mein koi channel ya playlist nahi hai. Aapko apni khud ki ya
jiski ijazat ho wahi M3U playlist use karni hai.
